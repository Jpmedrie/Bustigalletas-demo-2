---

## 🖼️ Cómo agregar las imágenes

Las imágenes deben colocarse en la carpeta `images/` con estos nombres exactos:

| Archivo esperado | Imagen original |
|---|---|
| `images/logo.png` | Logo sin fondo |
| `images/brownie_rellena.jpg` | Brownie_rellena.jpg |
| `images/chispas_chocolate_partida.jpg` | Chispas_chocolate_partida.jpg |
| `images/red_velvet.jpg` | Red_Velvet_relleno_queso_crema_2.jpg |
| `images/muestra_de_caja.jpg` | Muestra_de_Caja_1.jpg |
| `images/muestra_chispas.jpg` | Muestra_chispas_2.jpg |

> **Sin imágenes**: el sitio funciona perfectamente con degradados y emojis como fallback. Las imágenes enriquecen la experiencia pero no son requeridas para que la página funcione.
